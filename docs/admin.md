# 运营管理台

目录`apps/admin`，React + TypeScript + Vite，保留原中文蓝色视觉。默认本机`http://127.0.0.1:5173/`，API可在登录页“连接设置”填写完整地址或同源`/api`。

```sh
npm --prefix apps/admin install
npm --prefix apps/admin run dev
npm --prefix apps/admin run build
```

构建执行TypeScript检查和Vite生产编译。部署模板及备份恢复说明见`deploy/README.md`。

## 正式账号与开发入口

默认使用`POST /auth/management/login {username,password}`登录；前端不提交角色字段，平台或商户权限以服务端账号绑定为准。系统没有默认密码，账号由受控本机CLI创建、重置、停用或解锁，详见部署说明。

密码不写入浏览器持久存储。令牌仅保存在当前标签页sessionStorage，绑定API地址；会话失效返回登录，退出调用服务端注销并清除此账号的本标签页草稿。开发入口仅在`/config.devAuthEnabled=true`时显示，界面明确标注开发会话；生产配置关闭开发身份及开发付款。

当前AppID和微信支付尚未接入。管理账号可以维护运营数据，但真实顾客微信登录和真实收款仍有独立接入步骤。管理台从不把开发付款或内部余额记账展示为微信实际扣款、微信原路退款或商户提现成功。

## 可用运营功能

- 经营概览：订单、商品、批次、待审商户；“净收款（含货款）”按已收减已退统计，不按利润或平台佣金解释。
- 商户：录入入驻、审核或拒绝并保存原因；平台可暂停/恢复经营。商户会话只管理所属商户数据。
- 社区与自提点：新增、维护真实站点及地址、停用。历史订单使用服务器保存的社区快照。
- 商品：新建/编辑整件与拆分规格、上/下架、分类标签、冷链。售价精确到整数分，输入最多两位小数，不静默四舍五入。
- 库存：显示`inventoryUnits/inventoryScale`换算的整包可售容量；旧库存待复核有明确提示。新建商品可初始化整包数；已有商品必须使用独立盘点操作并记录原因，不能通过普通编辑覆盖库存。
- 批次：维护门店、采购负责人、排期；采购清单按有效规格汇总；截单处理未成团；取消整个批次时由服务端检查已履约订单并退款。不能在普通状态下拉中直接取消或重开已截单批次。
- 订单：按订单、顾客、状态、商户、批次筛选；查看原价快照、有效/取消数量、实际商品金额、售后抵减、净收款、已退款和待补款。
- 履约：按采购→分装→待提/配送→完成顺序推进；自提需输入顾客出示的提货码。待补款或待处理售后由服务器阻止交付。
- 缺货/取消：按稳定行ID及数量取消，保留原下单量、累计取消量与原因；可明确选择是否恢复库存，缺货默认不恢复。费用和退差由服务端重算。
- 售后：查看顾客申请、批准具体退款金额或拒绝并说明原因；协商退款进入顾客平台余额。已完成订单的退款不把履约状态改回未完成。
- 称重：交付前填写有效商品实际总额及原因；多退余额、少生成待补款，不静默扣余额。全部缺货使用取消操作，不将称重金额写0。
- 私有凭证：PNG/JPEG/WebP单张≤5MB；服务端转JPEG、去EXIF，最多40张/单；列表和二进制图片均通过身份授权。前端用Bearer fetch+blob预览/下载，收起或离开销毁object URL。原HTTPS URL字段只作兼容。
- 钱包：仅平台查询顾客完整余额及流水；商户在所属订单查看退款/补款。
- 对账：按商户、批次显示实收、退款、净收、应付、待补款、钱包退款与差异，并下载CSV。CSV对可执行公式前缀作文本处理。
- 操作审计：读取服务端最近500条所属权限范围内的业务操作、操作者、原因和变更前后。账号登录等安全事件另由后端安全审计保存，不宣称为外部不可篡改存证。

## 输入与重试

商品/规格、批次、社区、库存盘点、订单进度说明、凭证链接、称重输入、退款/取消、售后审核草稿均保存在当前标签页，按API与用户隔离。关闭弹窗或网络错误后可继续；显式重置或退出账号清理草稿。点击遮罩不再直接丢弃表单。

库存和订单财务操作的请求标识与草稿一起保存，网络重试保留同一标识；确认成功后新操作获得新标识，按钮请求期间禁用。最终金额、库存容量、累计退款限额、商户隔离、状态转换和幂等均由服务端原子校验。浏览器草稿不是业务凭证，不能代替服务器保存。

未提交的本地文件选择无法跨页面保存；上传失败需保留当前页面并核对凭证列表后重试。

## 验收范围

本轮使用隔离API8791、临时正式QA管理账号和明确标记的测试订单，无真实资金。实际浏览器通过：正式账号密码登录、售后5元审核、原付24/售后抵减5/应付19/已退5显示；随后缺货取消1包，实际商品10/应付9/累计退款15显示。私有QA图片由API上传，再由管理台Bearer加载为blob预览，并检查可下载/收起。图片明确写有“TEST FIXTURE - NO REAL PURCHASE”，不是伪造采购小票。

自动化文件选择被当前Chrome扩展的文件URL访问权限阻断，未改变浏览器权限；因此不能声称“选择文件→上传”整条浏览器自动化已通过。服务端上传与管理台授权预览已分别实测。
