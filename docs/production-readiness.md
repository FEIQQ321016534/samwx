# 运营加固与正式上线验收

评估日期：2026-11-03（北京时间）。当前结论：**可在本机/隔离测试环境验收核心运营流程，尚不能标记为可直接承接真实交易的商用版本。** 2026-11-04已配置真实AppID与服务器受限密钥文件，sam.mmailife.com管理台HTTPS和管理员登录验收通过；真实微信用户登录、支付、商户结算及完整云端业务验收仍缺失，不能用模拟支付或环境变量存在来代替。

## 本轮已实现的运营与安全能力

| 范围 | 实现与验证内容 |
| --- | --- |
| 资金 | 服务端整数分核价、建单请求幂等、付款/补款/退款幂等、余额不透支、退款不超过净收款；缺货部分取消、整批取消、售后申请和审核、保留履约历史的协商退款 |
| 拼份库存 | 用精确整数单位处理整件、半份、三分之一等共同库存；旧版本已扣过库存的商品标记待实盘复核，禁止猜测真实库存继续销售 |
| 快照 | 订单保存商户、社区、采购批次、规格及价格快照；商户修改资料或规格不会改写既有订单与拼团 |
| 客户体验 | 购物车本地恢复、采购批次选择、超过六个商户/社区的搜索选择、失效身份清理、异步刷新防串商户、正确上海时间、取消未付款单、售后申请与查询 |
| 管理身份 | 独立正式管理账号，无默认账号密码；本地受控CLI建号，scrypt密码哈希、登录限速/锁定、禁用/重置撤销会话，微信顾客身份不自动获得管理权限 |
| 权限与隐私 | 商户隔离和暂停商户实时限制；令牌摘要入库；公开目录不返回参与者用户ID、订单ID、商户私密联系人或采购凭证 |

| 运维 | 默认生产运行策略、开发身份禁止公开绑定、可信代理CIDR、日志脱敏、数据库在线快照及媒体备份、停机恢复校验和会话清除 |

凭证当前保存在本地私有数据卷，尚未实现腾讯云 COS 适配。数据库当前仍是 SQLite 单实例。以上能力不是对未部署系统的安全认证，也不是容量保证。

## 尚未通过的上线门槛

1. **微信账号与主体**：AppID已提供且凭据验证通过；继续确认经营主体及类目，并完成合法服务器域名、真实用户登录、隐私声明、真机调试、分享和订阅通知等所需平台配置。个人主体与多代购商实物交易的收款条件须按官方渠道确定。
2. **支付和结算实现**：确定平台收付通/服务商等实际方案；实现并联调真实预支付、签名和通知验签、查单补偿、微信账单对账、退款、商户进件与结算。当前 `wechat` 付款明确返回未配置。
3. **余额业务确认**：当前是退款记入内部余额，可后续消费；没有充值、提现或转账。内部余额入账不等同微信原路退款。真实资金保管、商户退出、账户注销和余额处理规则需要结合最终收款方案确定。
4. **数据库迁移**：正式目标为 PostgreSQL；当前 SQLite 代码没有伪装成 PostgreSQL 适配器。需完成模型迁移、事务/锁竞争回归、账本核对、备份与恢复、切换及回滚演练后使用。
5. **云端上线验证**：sam.mmailife.com的管理台HTTPS已完成，Certbot自动续期演练通过；仍需微信平台合法域名配置、私网PostgreSQL、私有COS、告警、周期性异机备份、云端完整恢复和压力测试。
6. **经营资料和流程**：实际采购门店、可服务社区、配送范围、商品与分装资质、真实商户资料、隐私与售后规则、客服及异常处理人员尚待经营者提供和确认。软件不会代为生成“官方授权”“无菌操作”等未经确认的承诺。
7. **供应链告警**：API和管理台运行依赖本次审计无已知告警；小程序生产分类仍有7项中危，完整工具链仍有14项高危和1项严重告警。详见 [依赖审计](dependency-audit.md)，不能将范围不同的审计结果合并称为“全项目无漏洞”。

执行 `npm run release:check` 可查看当前明确的阻塞项。该检查故意不因填写假AppID或假支付配置而放行；开发测试成功不代表真实收款验收完成。

## 腾讯云路线与最低配置

用户确认首期每天100笔以内。按单台应用服务器规划；数据库与对象存储单独服务，暂不引入Redis或多应用实例。日订单量不能直接换算高峰并发，需在真实服务器测截单前集中下单。

服务端继续使用 TypeScript + Node.js + Fastify；正式数据库目标 PostgreSQL，图片与采购小票使用私有 COS。先采用模块化单体与后台任务扫描，避免在当前业务规模未确定时引入微服务和 Kubernetes。Redis 根据实际队列、缓存和跨实例限流需求再增加。

| 阶段 | 建议起点 | 限制 |
| --- | --- | --- |
| 开发测试 | 2核2GB，40GB以上SSD | 不作为真实交易容量承诺 |
| 小规模试运营预算 | 2核4GB，60GB以上SSD，5Mbps起，图片走COS | 单机方案仍有单点风险，需要异机备份；真实交易仍须通过上述上线门槛 |
| 正式多商户部署 | CVM 2核4GB起 + 同地域私网云 PostgreSQL + 私有COS | 云数据库单独计费；根据压测选择规格，后续再考虑多应用实例与负载均衡 |

腾讯云官方当前价格表列有轻量服务器2核4GB/60GB SSD/5Mbps/500GB月流量常规65元/月的套餐。这是服务器参考价，不含云数据库、COS、额外流量和备份等费用，不代表CVM或整套系统总价；活动、续费及地域以购买页为准。[官方价格表](https://cloud.tencent.com/document/product/1207/73452/)

生产云数据库采用私网连接，备份需包括全量与WAL日志并做恢复验证。[PostgreSQL备份方案](https://cloud.tencent.com/document/product/409/94889)

COS采用私有桶，通过后端授权或短时预签名访问；密钥不下发至浏览器或小程序。[COS预签名说明](https://cloud.tencent.cn/document/product/436/35651)

多代购商收款应按真实主体和能力接入，不能把测试余额作为商户结算完成的依据。[微信小程序支付接入](https://pay.wechatpay.cn/doc/v3/merchant/4015459512)、[平台收付通](https://pay.wechatpay.cn/doc/v3/partner/4012086921)
